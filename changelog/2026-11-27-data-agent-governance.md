# 2026-11-27 Data Agents 기업 데이터 강의 개편
작성자: Sangwoo Mo(sangwoomo) | 대상: Data Engineering 17강 | 도구: Codex

> **한줄 결론: 기업 데이터 연결·접근과 공개·운영 세 꼭지로 구성한 60장 교안을 기존 17강 주소에 반영했다.**

POSTECH 요구사항: 기존 과목과 공개 주소 유지.

## 변경과 검수

공식 기업 사례와 합성 SQL 실습, 민감 데이터 접근·모델 처리·결과 공개 판단을 반영했다. 올해 17강 HTML과 PDF를 과목 정본과 대조하고 60쪽 렌더·실습·목차를 검수했다.

## 기각한 안과 이유

앞 강의의 일반 에이전트 루프 반복과 생산 수율 중심의 구성을 제외했다. 검증된 분석 결과라도 수신자와 업무 목적에 따라 공개 여부가 달라진다는 결정을 수업에서 직접 연습한다.

## 학생 관점 검토 후속 반영

16강의 일반 도구 호출·권한 설명을 실행 신원과 데이터 사용 목적 사례로 바꿨다. 17강의 세 꼭지를 같은 고객 사용량 질문과 서명된 반출 기록으로 연결했다. 파트너 자료의 숫자·판단 기준·수신처·승인 상태를 문제에 넣어 학생이 공개 여부를 결정할 수 있게 했다. 60쪽 HTML·PDF, 실습과 목차 검수를 거쳤다.

## 발표 흐름과 디자인 검수

첫 SQL 실습과 권한 실습을 앞당기고 원자료로 시작하게 했다. 19쪽 지연 적재 비교와 44쪽 역산 예를 막대로 설명하고 59쪽 결론 뒤에 참고 자료를 배치했다. 60쪽 전장 렌더·도식 경계·실습·목차를 확인했다.

## 75분 대면 수업 리허설

17강 HTML 발표자 노트에 한국어 진행 대사, 실습·응답 대기, 누적 시각과 지연 시 단축 순서를 반영했다. 본문 69분 11초와 질의응답·지연 예비 5분 49초로 구성했다. 60장 노트와 실습 8개 결과, 학생 화면 동일성을 확인했다.

## 강사 단독 설명판

한국어 원고만 Yuna 150으로 합성해 1~59쪽 발화 75분 09초를 측정했다. 기업 분석 24분 18초, 거버넌스 28분 48초, 운영 22분 03초. 학생 활동과 대기, 조작, 질문 시간은 0분으로 계산했다. 수치 검산, 데이터 사용 범위와 운영 판정을 강사가 설명하는 원고로 교체했다.

## 학생 화면과 발표 길잡이

학생 화면에 검색 필터별 3건·2곳과 4건·3곳, 조기 집계 원인, 외부 전달 승인, 감사 기록, 권한 변경 재시험, 파일 반출 차단 조건을 표시했다. 첫 장 한국어 노트에는 사례를 처음 접하는 발표자용 길잡이와 세 시연의 정답 위치를 넣었다.

## 집계 시점과 고객사 추적 사례

18~19쪽에서 화요일 조회 마감만 바꿔 월요일 집계를 재현하고, 20쪽에서는 같은 3→2에서 이틀 모두 사용한 고객사가 2곳 또는 0곳인 두 경우를 대조한다. 21쪽은 다음 조회에 필요한 키와 수신처 권한을 연결한다.
