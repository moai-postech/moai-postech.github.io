# 2026-10-26 하이픈 단어 대소문자 규칙

작성자: Sangwoo Mo(moai-postech) | 대상: `AGENTS.md` | 도구: Claude Code

> **한줄 결론: 라벨에서는 하이픈 뒤도 대문자(`Time-Series`), 문장 안에서는 소문자(`time-series`), 고유 제목·이름은 원문 그대로로 정했다.**

## 요청

교수: time-series 의 s 를 대문자로 할지 소문자로 할지, 하이픈 뒤를 하나로 정해 일관되게. 이름은 대문자.

## 반영 내역

- `AGENTS.md` 콘텐츠 표기 규칙에 한 줄 추가. 영어 제목 표기(title case)의 일반 관례대로 하이픈으로 이은 두 단어를 모두 대문자로 쓴다.
- 점검: 사이트의 라벨은 이미 모두 이 규칙을 따른다(멤버 주제 `Time-Series Analysis` 3명). 소문자 하이픈 단어(`real-world`, `non-visual`, `test-time`)는 모두 문장 안이다. `Time-series`, `Zero-shot`, `Taxonomy-guided`, `Vision-Language`, `Pixel-level` 은 논문·워크숍 원제라 고치지 않는다. 바꾼 콘텐츠는 없다.

## 기각한 안과 이유

- 라벨에서도 하이픈 뒤 소문자(`Time-series Analysis`): 같은 라벨 안의 다른 단어(`Analysis`)는 대문자인데 한 단어만 소문자라 어색하고, 지금 사이트의 라벨과도 어긋나 고칠 곳이 늘어난다.
- 논문 원제까지 규칙에 맞추기: 원제는 저자가 정한 표기라 바꾸지 않는다.
