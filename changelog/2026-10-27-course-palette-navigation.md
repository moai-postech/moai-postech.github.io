## 반영 내역
- 강의 공통 템플릿에서 Home의 Schedule & slides·Project 버튼 제거. 상단 Home·Schedule·Project 탭 유지. 별도 자료 링크가 있을 때만 본문 링크 줄을 생성하며, 빈 버튼 여백은 남기지 않음.
- Part 1 blue `#405f82` / 배경 `#edf2f8`, Part 2 teal `#3f7069` / 배경 `#edf5f2`, Part 3 violet `#725f87` / 배경 `#f3eff7`. 채도와 배경 명도를 맞춰 세 파트의 시각적 무게를 통일.
- 공통 개요·시험·프로젝트·평가는 분홍색에서 사이트의 중립 회색으로 변경. 초청·세미나는 더 옅은 회색. POSTECH Red는 선택한 탭·자료 링크·현재 일정 표시에서 유지.
- 같은 tone 역할을 쓰는 모든 강의 Home·Schedule·Project에 일괄 적용. AI Study도 공통 운영·초청 역할의 회색을 공유. 과목 데이터·파트 순서와 강의·발표 파일은 변경하지 않음.
- 강의 README의 팔레트와 Home 구조 설명을 구현과 맞춤.
- 실제 렌더에서 첫 파트 카드·평가 카드의 위 여백과 마지막 카드의 아래 여백이 사라지는 문제 발견. 전역 목록 가장자리 trim 규칙에서 파트·프로젝트 단계 카드와 평가 카드를 제외해 모든 카드의 내부 여백을 보존.

## 검증
- 같은 Schedule 화면에 기존 팔레트와 새 팔레트를 적용해 비교. 새 팔레트는 공통 일정과 자료 링크의 크림슨이 중복 경쟁하지 않고, 파트 구분은 유지.
- Jekyll 빌드, 전체 형식·POSTECH 검사 및 세 강의 Home·Schedule·Project와 Study를 1280·768·390px의 30조합에서 확인. 상단 탭 실제 클릭, 본문 중복 링크·빈 버튼 줄 제거, 가로 넘침 없음 확인.
- 세 과목의 파트 색상 일치 확인. 역할 글자색·본문·보조색·크림슨 링크의 실제 배경 대비는 검사 대상에서 최소 4.99:1로 4.5:1 이상. 카드 위·아래 padding이 같고 16px 이상인지 30조합에서 재검증.
- 원본 복구 경로: Git `d64a978`.

## 기각한 안과 이유
- 기존 파랑·초록·노랑·분홍 유지: 넓은 표에서 네 계열이 경쟁해 자료 링크와 선택 상태가 덜 명확함.
- 모든 파트를 같은 회색으로 통일: 긴 스케줄을 파트 단위로 훑기 어려워짐.
- 강의마다 다른 팔레트: 같은 Part 역할의 색이 바뀌어 통일감이 사라짐.
- 본문 버튼 제거 후 빈 문단 유지: 소개 아래 불필요한 간격이 남음. 별도 링크가 있을 때만 생성.
- 첫·마지막 카드에만 별도 padding 덧붙이기: 카드 여백을 지우는 전역 목록 규칙의 적용 대상을 바로잡음.
