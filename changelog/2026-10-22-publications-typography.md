# 2026-10-22 Publications 글자 배치와 간격 점검
작성자: Sangwoo Mo(moai-postech) | 대상: Publications > By Year (`_themes/wide/includes/theme.css` 의 publications 규칙) | 도구: Claude Code

> **한줄 결론: 번호 기준선 1px 어긋남, 위첨자로 늘어난 저자 줄, 토큰 밖 항목 간격, 연도 제목 자간을 고쳤고 나머지는 이미 맞았다.**

## 요청
교수: publication 페이지의 글자 배치, 간격이 디자인적으로 완벽한지 판단해 달라.

## 측정 (1440px, 글자 상자 기준)
| 항목 | 전 | 후 |
| --- | --- | --- |
| 번호와 제목 기준선 차이 | 번호가 1px 위 | 0 |
| 저자 줄 높이(위첨자 있음/없음) | 25 / 22.5px | 22.5 / 22.5px |
| 논문 사이(앞 논문 끝 글자 → 다음 제목) | 34.5px(padding 16px, 토큰 아님) | 26.5px(`--item-gap`) |
| 연도 제목 → 첫 제목 | 27.5px | 19.5px |
| 마지막 논문 → 다음 연도 제목 | 81px | 77px |
| 연도 제목 자간 | -0.6px(Talks 연도는 0) | 0 |

- 위계: 항목 안 줄 사이 약 9px < 연도 제목 → 첫 논문 19.5px < 논문 사이 26.5px < 절 사이 77px. 전에는 연도 제목 → 첫 논문(27.5)과 논문 사이(34.5)가 둘 다 넓어 위계는 섰지만 토큰 규칙에서 벗어나 있었다.
- 이미 맞던 것: 배지와 Oral 4px, 링크끼리 12px, 구분선 양쪽 12px, 배지와 링크 글자의 세로 중심 차 0.5px, 두 줄 제목의 둘째 줄 왼쪽이 첫 줄과 같음, 1440·1024·820·375px 에서 가로 넘침 0, 휴대폰에서 venue 줄이 줄바꿈되지 않음.
- 820, 1024, 375px 에서도 위 수치가 같다(375px 은 번호 칸 2.5em 이라 번호와 제목 사이 최소 10px).

## 반영 내역
- `.pub-num`, `.pubs .title` 에 `align-self: baseline`. 번호 칸 `line-height: 1.65` 는 뺐다.
- `.page-publications sup { line-height: 0; }`: * † 가 있는 저자 줄이 2.5px 더 높던 것을 없앴다.
- `.pubs li` 의 위아래 padding 을 `var(--space-4)` 에서 `var(--item-gap)` 으로(AGENTS.md 세로 간격 두 단계 규칙).
- `.page-publications h2` 아래 여백 24px → 16px. 논문 사이를 좁히자 연도 제목이 첫 논문과 논문끼리보다 멀어져, 제목이 아래 목록에 붙어 읽히도록 줄였다. 자간은 Talks·Seminar 연도와 같게 `normal`.

## 기각한 안과 이유
- 번호를 오른쪽 정렬해 번호와 제목 사이를 일정하게: 지금은 왼쪽 정렬이라 "C25" 뒤 17px, "J3" 뒤 29px 로 다르다. 오른쪽 정렬은 배치 방식 변경이라 고치지 않았다(아래 남은 것).
- venue 배지 위아래 padding 1px 을 0 으로 해서 배지 있는 줄(23.4px)과 링크만 있는 줄(21.4px)의 높이를 맞추기: 차이가 2px 이고 Preprints 절과 게재 절 사이에서만 생겨 눈에 띄지 않는다. 공용 `.venue` 규칙이라 Home 카드에도 걸린다.
- 수상 줄 위 4px 추가 여백을 없애 줄 간격을 완전히 고르게: 교수가 2026-10-21 에 "venue 줄에 너무 붙는다"며 넣은 것이라 유지.
