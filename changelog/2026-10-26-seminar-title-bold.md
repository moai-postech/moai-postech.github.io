# 2026-10-26 세미나 제목 굵게

작성자: Sangwoo Mo(moai-postech) | 대상: `_themes/wide/includes/theme.css` | 도구: Claude Code

> **한줄 결론: Seminar 목록에서 발표 제목을 굵게(600), 발표자 이름을 보통 굵기(400)로 바꿨다.**

## 요청

교수: "세미나 제목도 볼드 하는건 별로인가?" 뒤에 바꾸기로 함. AGENTS.md 의 "목록 한 줄의 '무엇'은 굵게"(2026-10-22, 발표 제목 포함)에 비해 Seminar 만 제목 400, 발표자 600 으로 거꾸로였다.

## 반영 내역

- `.schedule-title` 400 → 600(논문 제목 `.pubs .title` 과 같은 굵기).
- `.schedule-speaker` 600 → 400. 소속은 원래 400·회색이라 이름과 색으로 구분된다.
- 확인: 라이브 Seminar 페이지에 같은 CSS 를 입혀 1280px 화면으로 봄(이 맥에는 jekyll 이 없어 로컬 빌드는 못 함).

## 기각한 안과 이유

- 제목과 발표자를 둘 다 굵게: 한 줄에 굵은 글자가 둘이라 무겁고, "무엇"만 굵게 하는 규칙과 어긋난다.

## 2차 (2026-10-26): 제목 중간 굵기, 연사 강조

교수: "연사도 강조하고 싶은데, 제목을 중간 굵기로 하고 연사를 강조하는 건 어때?" 세미나 목록은 누가 발표하는지가 중요해, 1차와 반대로 연사를 굵게 둔다.

- `.schedule-title` 600 → 500(중간 굵기, 본문 400 보다는 눈에 띔).
- `.schedule-speaker` 400 → 600(1차 이전 굵기로 되돌림). 소속은 400·회색 그대로.
- 확인: 라이브 페이지에 같은 CSS 를 입혀 1280px 로 봄.
- "목록의 '무엇'만 굵게" 규칙의 예외: Seminar 는 연사를 굵게, 제목을 중간 굵기로 한다.

기각한 안: 1차(제목 600, 연사 400). 연사가 묻혀서 교수가 되돌림.

## 3차 (2026-10-26): 연사 열을 따로, 이름 먼저

교수: "세미나 페이지 뭔가 못생겼는데 검토". 1280px 와 375px 로 재 보니 (1) 제목 17px·500 과 연사 15px·600 이 크기와 굵기에서 서로 엇갈려 강조가 흐렸고, 500 은 테마의 굵기(400·600·700) 밖이었다. (2) 연사 칸이 "소속 + 이름"을 오른쪽 끝에 맞춰, 소속 길이에 따라 이름 시작점이 줄마다 달랐다. (3) 제목과 연사 사이 빈 폭이 넓다(제목 칸 875px, 제목 중간값 567px). 시안을 브라우저에서 보이고 교수가 골랐다.

- `sections/seminar.html`: 연사 칸에서 소속을 떼어 오른쪽 넷째 열(`.schedule-aff`, `col-aff`)로. 연도 행 `colspan` 3 → 4. 열 폭 고정 스크립트는 열 수와 무관하게 동작해 그대로 둠.
- `theme.css`: 제목 500 → 400, 연사는 600 그대로 두고 왼쪽 정렬, 소속은 회색·작은 글자 열. 휴대폰은 제목 아래 한 줄에 이름, 그 뒤 소속.
- 확인: 이 맥은 Ruby 2.6 이라 jekyll 빌드를 못 해, 라이브 페이지에 같은 구조와 CSS 를 입혀 봄. push 뒤 라이브에서 필터 전환과 375px 를 다시 확인.
- 3번(빈 폭)은 "넓게 쓰고 누구·어디는 오른쪽" 원칙상 남긴다. 이름 열이 반듯해져 덜 거슬린다.

- 3차 보정: 휴대폰에서 소속이 이름 다음 줄로 떨어졌다. 휴대폰 규칙 `.schedule-aff` 가 위의 `.schedule td { display: block }` 보다 약해서라, 선택자를 `.schedule td.schedule-aff` 로 올렸다.

기각한 안: 2차(제목 500, 연사 오른쪽 끝 정렬). 굵기 500 이 테마 밖이고 이름 시작점이 들쭉날쭉했다. 연사를 제목 바로 뒤에 붙이기: "왼쪽 무엇, 오른쪽 누구" 원칙에 어긋난다.
