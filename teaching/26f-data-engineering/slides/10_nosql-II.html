Matching Nested Fields

db.inventory.find(

find result
{ "item": "planner", "size": { "h": 22.85, "w": 30, "uom": "cm" } }
A dotted path tests a field inside the nested object

Exact Arrays or Contained Values

Exact array, including order

db.inventory.find(
  { tags: ["red", "blank"] },
  { _id: 0, item: 1, tags: 1 }
)
find result
{ "item": "notebook", "tags": [ "red", "blank" ] }

Contains red and plain

db.inventory.find(
  { tags: { $all: ["red", "plain"] } },
  { _id: 0, item: 1, tags: 1 }
)
find result
{ "item": "paper", "tags": [ "red", "blank", "plain" ] }
An array equality checks the whole sequence; $all checks membership

Preserving an Array in Projection

db.inventory.find(
  { item: "paper" },
  { _id: 0, item: 1, "instock.loc": 1 }
)
find result
{ "item": "paper", "instock": [ { "loc": "A" }, { "loc": "B" } ] }
Projection removes fields while preserving the array structure

Caveat: A Mistyped FieldOne document stores qty as the string "50"; the range filter skips it without an error

db.inventory.find(
  { qty: { $gte: 30 } },
  { _id: 0, item: 1, qty: 1 } )
qty at least 30: notebook (50) is missing
{ "item": "paper", "qty": 100 }
{ "item": "planner", "qty": 75 }
{ "item": "postcard", "qty": 45 }
db.inventory.find(
  { qty: { $type: "string" } },
  { _id: 0, item: 1, qty: 1 } )
why: its qty is a string
{ "item": "notebook", "qty": "50" }
Remedy: validate qty as numeric before accepting the document
This numeric query predicate skips string values; numeric BSON types remain comparable

Lookup on a Shared Key

db.items.aggregate([
  {$lookup: {from: "suppliers",
             localField: "supplier", foreignField: "supplier",
             as: "details"}},
  {$project: {_id: 0, item: 1, details: 1}}
])
aggregate result
{ "item": "journal", "details": [ { "supplier": "S1", "country": "US" } ] }
{ "item": "paper", "details": [ { "supplier": "S1", "country": "US" } ] }
{ "item": "postcard", "details": [ ] }
An unmatched supplier produces an empty array, not a missing item
