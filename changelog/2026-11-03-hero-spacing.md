# 2026-11-03 Home 히어로 위아래 여백을 32px 로 같게
작성자: Sangwoo Mo(moai-postech) | 대상: `_themes/wide/includes/theme.css` | 도구: Claude Code

> **한줄 결론: 히어로 그림 위 64px, 아래 32px 로 위가 두 배였다. 위도 32px 로 줄여 메뉴 선과 단체사진 사이에서 그림이 가운데 오게 했다.**

POSTECH 요구사항: 머리글·꼬리말을 건드리지 않았다. P1~P9 영향 없음.

## 요청
교수: Home 히어로의 세로 여백이 언밸런스하다. 그림 위 여백이 원래 이렇게 길었나.

## 원인
- `.hero` 의 padding 은 위 `--space-8`(64px), 아래 `--space-6`(32px)이었다. 위는 2026-10-27 [design-balance](2026-10-27-design-balance.md) 에서 96 → 64, 아래 32 는 2026-10-21 [design-sweep](2026-10-21-design-sweep.md) 에서 다음 절 위 32 와 더해 64 가 되도록 정한 값이다.
- 같은 날 [venue-badge-size](2026-10-27-venue-badge-size.md) 에서 단체사진을 히어로 바로 아래 붙이며 사진 위 여백을 0 으로 했다. 그 뒤로 그림 아래는 32px 만 남아 위 64px 와 짝이 맞지 않았다. 1440px 에서 잰 값: 메뉴 선 → 그림 64px, 그림 → 사진 32px.

## 반영 내역
- `.hero { padding: var(--space-6) 0 }`: 위아래 32px. 사진을 히어로 바로 아래 두는 교수 결정(아래 32px)은 그대로다.
- 태블릿·휴대폰은 그림을 숨기고 각자 padding 규칙이 있어 바뀌지 않는다.

## 기각한 안과 이유
- 위아래 48px: 띠 전체 높이는 지금과 같지만, 사진 위 여백을 32px 로 둔 2026-10-27 결정을 되돌린다.

## 확인
- 라이브 페이지(1440px)에 같은 CSS 를 넣어 화면 한 번 확인. 읽은 규칙: `AGENTS.md`(형식은 전역 규칙으로, 세로 간격 토큰).
