# 2026-11-23 글자 크기 단계 정리

작성자: Sangwoo Mo(sangwoomo) | 대상: `theme.css`(`--fs-4`, `--text-group`), `page-design` | 도구: Claude Code

> **한줄 결론: 큰 글자 단계를 본문 16 / 소개·카드 이름 18 / 묶음 제목 20 / 절 제목 26(휴대폰 24)으로 정리했다. 1px 차이로 붙어 있던 19와 20을 갈랐다.**

POSTECH 요구사항: 영향 없음

## 요청
교수: 전체 글자 크기를 가장 예쁘게, 디자인 스킬(design-system 감사)로 꼼꼼히 검수.

## 감사(빌드 결과 89쪽, 1440px·390px 에서 보이는 모든 글자의 크기·굵기를 모음)
- 데스크톱 단계: 13, 14, 15, 16, 19, 20, 23, 26, 46. 휴대폰: 13, 14, 15, 16, 18, 20, 24, 32.
- 문제 1: 데스크톱 19(소개 문장, Faculty 직함, 멤버 카드 이름, 카드 제목 h3, 꼬리말 로고)와 20(묶음 제목)이 1px 차이다. 굵기가 비슷한 멤버 이름(19/600)과 `PhD Students`(20/700)는 같은 크기인데 실수로 어긋난 것처럼 보였다.
- 문제 2: 휴대폰은 소개 18, 묶음 20 으로 이미 2px 떨어져 있어 데스크톱과 단계 관계가 달랐다.
- 그 밖(13 날짜·표 머리·꼬리말, 14 보조, 15 메뉴·필터·세 페이지 오른쪽 칸, 16 본문, 23 머리글 로고, 46 큰 제목)은 역할마다 하나의 크기라 그대로 둔다. 15px 오른쪽 칸은 교수 결정(`.page-courses` 등)이다.

## 반영 내역
- `--fs-4` 19px → 18px. 소개 문장·직함·카드 이름·h3 가 데스크톱과 휴대폰 모두 18px.
- `--text-group` 20px 유지(주석만 고침). 이제 16 / 18 / 20 / 26 이 모든 화면에서 같은 관계다.
- 실제 사이트에 덮어 Home 히어로, Faculty, Members, Courses 를 데스크톱·휴대폰에서 확인. 재측정한 데스크톱 단계: 13, 14, 15, 16, 18, 20, 23, 26, 46.
- `page-design.json`·`.md` 의 강의 Home 근거 문장 `소개19px` → `소개18px`.

## 기각한 안과 이유
- 19 와 20 을 20 하나로 합치기: 소개 문장(20/400)과 묶음 제목(20/700)이 같은 크기가 되어 Faculty 의 직함과 `Bio` 가 맞먹었다. 휴대폰에서 18 로 합쳐 보니 `Bio` 가 직함보다 작아 보였다.
- 멤버 카드 이름만 16px: 아래 굵은 연구 주제(14/600)와 구분이 약해짐.
- 묶음 제목 22px: 같은 날 앞 회차에서 절 제목과 경쟁해 기각(`2026-11-23-group-heading-size.md`).

## 남은 것
- 17px 가 한 군데 남았다: Home 연구 방향 동심원 SVG 의 고리 이름. 다른 세션이 작업 중(`2026-11-23-focus-rings.md`)이라 손대지 않았다. 18 이나 16 으로 맞추면 단계에서 벗어나는 크기가 사라진다.
- 로컬 `check_design`·`check_typography` 는 이 맥에서 Playwright 내장 Chromium 이 실행되지 않아(spawn -88) 돌리지 못했다. 실측은 시스템 Chrome 으로 했다.

## 후속: 마감 검수(같은 날)
교수: 계속 돌면서 꼼꼼하게 디자인 검수, 마감이 가장 중요.
- 15쪽(Home, Overview, Publications, Funding, Faculty, Members, Other Mentees, Courses, Study Group, Lab Seminar, Invited Talks, Contact, News, AI Study, 강의 Home)을 1440px·390px 전체 화면으로 캡처하고, 하위 탭→소개→첫 묶음, 마지막 내용→꼬리말 간격을 쟀다. 하위 탭 아래 48px(휴대폰 16px), 소개 아래 24px, 꼬리말 앞 64px 로 모든 페이지가 같다.
- 고침: Members 카드의 연구 주제가 굵어(16/600) 이름(18/600)보다 진해 보였다. 주제를 보통 굵기로 낮춰 이름 → 주제(본문색) → 학력(회색) 세 층이 갈린다. 계약(`person-card-secondary`)은 크기만 정해 그대로 맞는다.
- 기각: 이름만 굵기 700 으로 올리기(묶음 제목 700 과 같아져 `PhD Students` 와 다툼), 주제를 회색으로(학력과 같아져 층이 둘로 줄어듦).
- 이슈로 보고만 함: Faculty 의 Honors & Awards 는 오래된 것부터(2019→2022), 같은 페이지 Appointments 는 최신부터다. 순서는 콘텐츠 결정이라 손대지 않았다. Home 의 `Research Focus` 제목만 가운데 정렬이고 아래 상자에 빈 공간이 크다. 다른 세션이 작업 중(`2026-11-23-focus-rings.md`)이라 손대지 않았다.
