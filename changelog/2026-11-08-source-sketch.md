# 2026-11-08 Home 실제 사진 색보정
작성자: Sangwoo Mo(sangwoomo) | 대상: Home 사진, AGENTS.md | 도구: Codex, Google API

> **한줄 결론: 스케치를 실제 단체사진으로 교체하고 명암과 초록색 채도만 가볍게 보정했다.**

POSTECH 요구사항: 영향 없음.

## 요청
사용자는 기존 사진이 원본인 것으로 보고 그 사진으로 작업을 계속하라고 요청했다. 닮음과 자연스러운 미화를 함께 목표로 한다.

## 반영 내역
- 기존 `group-2026.jpg`의 여덟 얼굴을 각각 참조했다. 반려된 그림은 Google 입력에서 제외했다. `gemini-3-pro-image`로 3:4·1K 인물화를 생성했다.
- 미화는 깨끗한 연필선·피부·빛으로 요청했다. 첫 결과 중 네 얼굴의 새 치아 미소를 기각하고 닫힌 입과 실제 눈 크기를 강조해 재생성했다. 총 12회 정상 응답을 확인했다.
- 기존 스케치의 머리 마스크 안에만 반영했다. `group-2026-sketch-source.png`는 1732×908이며 머리 마스크 밖 픽셀은 기존 공개 스케치와 같다. 원본과 모든 기존 시안은 보존했다.
- 로컬 Home 참조를 새 시안으로 바꿨다. `AGENTS.md`에 기존 원본으로 진행하는 사용자 결정과 후보·공개본 구분을 반영했다. 공개 사이트에는 아직 적용하지 않았다.
- 원본·공개 스케치·새 시안 비교판, 입력, 프롬프트, 응답 정보, 재현 스크립트, 검증 해시는 `visual-review-bundle/google-source-redraw/`에 있다.

## 기각한 안과 이유
- 반려된 스케치 얼굴을 인물 기준으로 재사용하면 달라진 특징을 이어받는다.
- 원본에 없던 넓은 미소를 추가한 첫 결과 네 장은 제외했다. 원본과의 유사성이나 미화 성공을 자체 판단만으로 확정하지 않는다.

## 검증
프로젝트 및 상위 AGENTS.md, rules/secrets.md·memory-location.md·workflow.md와 기존 imagegen 스킬 지침을 따랐다. 여덟 얼굴의 원본·전후 비교와 전체 그림, 해상도, 머리 마스크 밖 픽셀 일치를 확인했다. Jekyll 빌드와 diff 공백 검사를 통과했다. 별도 headless Chrome에서 로컬 Home의 새 src·1732×908·이미지 로드 완료를 확인하고 `home-final.jpg`를 렌더해 검토했다.

## 남은 것
별도 디자인 결정 없음. 사용자가 실제 사진과 가벼운 색보정의 홈페이지 적용을 승인했다. 이전 스케치 공개 요청은 종료했다.


## 얼굴 크롭·붙이기 금지
- 사용자가 합성이 어색하다고 지적하고 크롭·붙이기를 명시적으로 금지했다. 얼굴별 생성과 머리 마스크 합성 방식을 기각했다. 앞선 원본 기준 얼굴 합성 시안은 게시 후보가 아니다.
- AGENTS.md에 전체 원본 한 번 변환과 얼굴 크롭·합성 금지를 명시했다. 원본 사진 전체 한 장만 Google API 입력으로 사용하며 출력 그림도 통째로 사용한다.
- 전체 변환의 입력·프롬프트·응답은 `visual-review-bundle/google-whole-photo/`에 보관한다. 이전 파일과 원본은 보존했다.

- 크롭 전 로컬 원본 2000×1333 전체를 최종 입력으로 사용했다. Google이 반환한 전체 그림을 `assets/img/lab/group-2026-sketch-whole.jpg`에 바이트 변경 없이 복사했다. 최종 그림은 크롭·얼굴 마스크·붙이기·후처리를 하지 않았다. 최초 웹용 가로 사진 입력 결과는 비교용으로 별도 보존했다.
- 여덟 인물·M 손동작·전체 구도와 그림 전체를 눈으로 확인했다. 원본과의 닮음·미화 성공은 사용자 평가 전에 확정하지 않는다. 파일 해시로 Google 반환본과 프로젝트 이미지의 일치를 확인했다.


## 최종 결정: 실제 사진과 가벼운 색보정
- 사용자가 사이트와 어울리는 최선의 방향을 물었다. 선명한 글자·간결한 도식과 실제 연구실 분위기에 맞춰 원본 사진의 어두운 부분과 초록색 채도만 정돈하는 안을 제안했고, 사용자는 그 안을 적용하도록 승인했다.
- `tools/tone_home_photo.py`는 원본 해시를 확인한 뒤 3D 색 변환 LUT 하나를 사진 전체에 적용한다. 어두운 부분에 최대 약 11단계의 밝기를 더하고 초록색이 강한 픽셀의 채도를 최대 12% 낮춘다. 새 얼굴 생성·크롭·합성·리사이즈·형태 변환은 하지 않는다.
- 결과는 `assets/img/lab/group-2026-natural.jpg`다. 원본의 1780×933 크기와 모든 위치를 유지한다. Home src·캐시 버전·사진 alt를 갱신하고 AGENTS.md의 최종 원칙을 실제 사진과 색보정으로 바꿨다. 스케치 재작업 TODO는 종료했다.
- 이전 미게시 리터치 커밋은 최종 사진 변경으로 대체하고 반려한 새 생성 얼굴 이미지는 게시할 변경에서 제외한다. 원본과 기존 시안은 비교용으로 보존한다.
- 기각: 생성 스케치는 실제 얼굴을 바꾸고 사이트보다 질감이 많다. 얼굴 합성은 어색하고 사용자가 금지했다. 원본 사진은 인물을 그대로 전달하고 사이트의 선명한 표현과 맞는다.

- 최종 검증: 원본 SHA256과 1780×933 크기 확인, Jekyll 빌드 통과, PC 1440px·모바일 390px Home 렌더를 직접 확인했다. 두 화면에서 새 사진 src·원본 크기·로드 완료를 확인했다. 얼굴·표정·손동작을 그대로 두고 사이트 배치를 유지했다. 기록과 현재 원칙을 함께 갱신했다.
