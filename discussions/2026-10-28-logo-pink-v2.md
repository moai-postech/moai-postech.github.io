# 2026-10-28 새로 받은 분홍(#C7005D) 로고 파일로 운영 로고를 교체할지
상태: 논의 중 | 제안자: Chaewon Park(onehanap) | 대상: `assets/img/logo-moai.svg`, `assets/img/favicon-moai.svg`, `assets/img/apple-touch-icon-moai.png`

## 쟁점
교수에게 새 로고 묶음(`moai-logo.zip` v2)을 받아 운영 로고로 반영해 달라는 요청이 들어왔다. 지금 운영 로고는 같은 날 [logo-candidate-review](../changelog/2026-10-28-logo-candidate-review.md) 에서 C안(`refinements/03-compact-angular.png`)의 기하를 손으로 정리해 만든 `#A61955` 단색 SVG다. 새 묶음을 그대로 쓰면 그 정리본 대신 원본 묶음의 벡터가 들어가고 색도 바뀌므로, 그 회차의 결정을 바꾸는 일이 된다. 받은 파일을 그대로 운영에 올릴지, 지금 정리본을 유지할지 정한다.

POSTECH 요구사항: P2, P9 확인. 머리글·꼬리말의 POSTECH 워드마크와 링크는 어느 안에서도 그대로다(P1, P3, P5, P8 영향 없음). P9 의 강조색 POSTECH Red `#a61955` 는 어느 안에서도 `theme.css` 의 `--red-700` 에 그대로 두고 바꾸지 않는다. 다만 안 A 를 고르면 머리글·꼬리말의 연구실 로고만 `#C7005D` 가 되어, 같은 화면의 강조색(링크 hover, 현재 메뉴 밑줄, Focus 띠)과 다른 분홍이 함께 보인다. 요구사항 표를 고치는 안은 없다.

## 받은 파일과 지금 파일의 차이
- 보관 위치: `assets/img/logo-candidates/moai-logo-v2.zip` 과 풀어 놓은 `assets/img/logo-candidates/moai-logo-v2/`. 보관 경위는 [logo-pink-v2-archive](../changelog/2026-10-28-logo-pink-v2-archive.md).
- v1(`logo-candidates/moai-logo/`)과 비교하면 **도형은 완전히 같고 색과 변형 구성만 다르다**. `brand #A61955` → `pink #C7005D`, `stone` → `gray`, `white` 와 `currentcolor` 추가. 검은색 SVG·PNG 는 바이트까지 동일하다. README 는 v2 에 없다.
- v2 의 로고 비율은 1122:2275(약 1:2.03)로, 지금 운영 중인 정리본(840:1290, 약 1:1.54)보다 가늘고 길다. [logo-candidate-review](../changelog/2026-10-28-logo-candidate-review.md) 가 이 비율을 두고 "기존 칸에 강제로 맞추면 찌그러지고, 높이만 맞추면 가늘고 작아 보인다"고 적었고, 그래서 C안의 넓은 비율을 골라 정리했다.
- ZIP 경로 탈출·심볼릭 링크, SVG 의 script·onload·외부 참조(`xlink:href`, `<image>`)는 없음을 확인했다.

## 선택지
### 안 A: 받은 v2 파일을 그대로 운영 로고로 (제안: Chaewon Park)
`assets/img/logo-moai.svg` 를 `logo-candidates/moai-logo-v2/svg/moai-logo-pink.svg` 로, `assets/img/favicon-moai.svg` 를 v2 의 `favicon/favicon.svg` 로, `apple-touch-icon-moai.png` 를 v2 의 `favicon/apple-touch-icon.png` 로 바꾼다. 색은 `#C7005D`. 받은 원본 벡터를 그대로 쓰므로 교수가 전달한 것과 화면이 정확히 일치한다. `theme.css` 의 강조색과 다른 그림(`hero.svg`, `contact-join.svg`)은 건드리지 않는다.
- 비용: 2026-10-28 에 정리한 C안 기하(넓은 비율, 얇은 받침)가 원본의 1:2.03 세로형으로 되돌아간다. 헤더 40px·꼬리말 30px·강의 바닥 19px 높이에서 다시 재야 하고, 16px favicon 의 식별력도 다시 봐야 한다.

### 안 B: 지금 정리본의 색만 `#C7005D` 로 (제안: Chaewon Park)
`logo-moai.svg` 와 `favicon-moai.svg` 의 `#A61955` 만 `#C7005D` 로 바꾸고, C안 기하와 지금 높이는 그대로 둔다. 새 묶음이 v1 과 색만 다르므로, 색 변경이 요청의 핵심이라면 이 안으로도 결과가 같다. 2026-10-28 회차의 형태 결정은 유지된다.
- 비용: 받은 SVG 파일 자체를 쓰는 것은 아니다. 요청이 "파일 교체"였다면 의도와 다르다.

### 안 C: 현재 상태 유지 (제안: Chaewon Park)
`#A61955` 정리본을 그대로 둔다. P9 의 POSTECH Red 와 로고 색이 한 값으로 유지되고, 같은 날 끝낸 형태·favicon 검토를 다시 하지 않는다.
- 비용: 교수가 새로 전달한 분홍이 사이트에 반영되지 않는다.
