# 2026-11-03 메뉴 탭 이름 검토, Publications 하위 탭을 List / Map 으로
작성자: Sangwoo Mo(moai-postech) | 대상: `_config.yml`, `landscape.md`, `AGENTS.md` | 도구: Claude Code

> **한줄 결론: Publications 하위 탭 `Paper List` 를 `Full List` 로 바꾸고, Paper Stella 페이지 머리에 무엇을 보여 주는 지도인지 한 줄 설명을 넣었다. 나머지 탭 이름은 그대로 둔다.**

POSTECH 요구사항: `_config.yml` 은 메뉴 하위 탭 이름 하나만 바꿨다. P1~P9 영향 없음.

## 요청
교수: Publications 아래 `Paper List` 와 `Paper Stella` 에서 Publications 와 Paper 가 겹친다. `Full List` / `Paper Stella` 로. Paper Stella 라는 이름은 유지하고, 처음 보는 사람을 위해 설명을 붙인다. 이어서 Teaching 의 Talks 를 Invited Talks 나 Research Talks 로 바꿀지와 다른 탭 이름 전체를 검토해 달라.

## 반영 내역
- `_config.yml`: Publications 하위 탭 `Paper List` → `Full List`(같은 날 [home-paper-stella-mini](2026-11-03-home-paper-stella-mini.md) 6차에서 `All Papers` → `Paper List` 로 바꾼 줄). 주소(`publications.html`)는 그대로.
- `landscape.md`: `intro` 한 줄 "A map of the papers we read, grouped by topic, with our own papers highlighted."
- `AGENTS.md`: "같은 내용은 한 곳에만" 의 지금 자리 목록에 있던 탭 이름.
- 같은 회차 5차에서 기각한 `Full List` 를 교수 결정으로 되살렸다. 근거: 메뉴가 이미 Publications 라 Paper 를 되풀이할 필요가 없고, Research 절 끝의 "Full publication list" 링크와 이름이 이어진다.
- 탭 이름 전수 검토 결과, 아래 탭은 바꾸지 않는다.
  - People: Faculty · Lab Members · Other Mentees(2026-10-30 교수 결정).
  - Research: Overview · Seminar · Funding.
  - Teaching: Courses · Talks. Talks 는 2026-10-21 에 `Invited talks` → `Selected Talks` → `Talks` 로 교수가 고른 이름이다.

## 기각한 안과 이유
- 메뉴 드롭다운 항목 아래 설명 줄: 테마의 메뉴는 이름만 그린다. 한 항목에만 설명을 다는 새 요소가 되고 하위 탭 줄과도 모양이 갈린다. 설명은 페이지 머리 한 줄로 충분하다.
- Home 띠에 설명 문장 추가: 미니 미리보기가 이미 별 지도를 보여 주고, 링크 이름이 "Explore our papers in Paper Stella" 다. 오늘 맞춘 띠 높이(216px)도 건드리게 된다.
- `List` / `Map`, `List` / `Landscape`: Map, Landscape 도 무엇의 지도인지 바로 와닿지 않는다(교수).
- Paper Stella 이름 자체를 바꾸기: 새 형태의 시각화라 어떤 이름도 한 단어로 설명되지 않는다. paper-stella 저장소, 공개판, 내부 도구, Home 띠가 모두 이 이름을 쓴다.
- `Talks` → `Invited Talks`: KSS Tutorial, POSTECH IME Seminar 처럼 초청 강연이 아닌 항목이 있고, 장소 칸의 "KSS Invited Talk" 와 겹친다.
- `Talks` → `Research Talks`: "Opportunities in IME as an AI Researcher" 처럼 연구 발표가 아닌 항목이 있다.

## 2차(같은 날): 소개 문장과 지도 사이 간격
교수: Paper Stella 소개 문장 아래 세로 여백이 너무 길다.
- 모든 하위 탭 페이지에서 소개 문장 뒤 첫 절까지는 `--page-start`(데스크톱 48px)로 같다. 다른 페이지는 그 아래에 절 제목이 와서 맞지만, Paper Stella 는 문장이 바로 아래 지도의 설명이라 떨어져 보인다.
- `theme.css`: `.page-intro + .embed-section` 을 `min(--space-5, --page-start)`(데스크톱 24px, 휴대폰 16px)로. 페이지 하나가 아니라 "소개 바로 뒤 삽입 화면" 역할 규칙이다. `_themes/wide/README.md` 역할표에 한 줄.

### 기각한 안과 이유(2차)
- 문장을 지도 아래 `caption` 으로 옮기기: 작은 회색 글씨가 되고, 지도를 보기 전에 무엇인지 알려 주려던 목적이 사라진다.
- `page-design.json` 에 landscape 한 페이지 조정으로: 같은 구조(소개 뒤 삽입 화면)가 생기면 또 따로 맞춰야 한다.
- `--page-start` 자체를 줄이기: 절 제목이 오는 다른 페이지의 리듬까지 바뀐다.

## 3차(같은 날): 탭 이름 List / Map
교수: `Full List` / `Paper Stella` 가 별로다. 더 간단한 느낌으로. `Visual Map`, `Topic Map` 을 견준 뒤 `List` / `Map` 으로.
- `_config.yml`: Publications 하위 탭 `Full List` → `List`, `Paper Stella` → `Map`. 주소는 그대로.
- Paper Stella 라는 이름은 탭에서만 빠진다. `landscape.md` 페이지 제목(브라우저 탭 `Paper Stella · MOAI Lab`), Home 띠의 "Explore Paper Stella", 공개판 사이트는 그대로다.
- `AGENTS.md` 지금 자리 목록, `index.md` 주석의 탭 이름.

### 기각한 안과 이유(3차)
- `Visual Map`: 지도는 원래 시각화라 Visual 이 뜻을 더하지 않고, 한 단어인 List 옆에서 무거워 보인다.
- `Topic Map`: 주제라는 말이 앞에 서서 10월의 `By Topic` 처럼 정렬 방식으로 읽힐 수 있다. 시각화라는 대비는 Map 하나가 가장 분명하다.
- `List` / `Stella`: 처음 온 사람이 메뉴만 보고 무엇인지 짐작할 수 없다.
- `Full List` / `Paper Stella`(1차): 교수가 마음에 들지 않아 했다.
- 10월 21일 `List` / `Visualization` 과 달리 Map 은 짧고, 탭 아래 설명 한 줄(1차)이 무엇의 지도인지 알려 준다.

## 4차(같은 날): 페이지 주소를 탭 이름에 맞춤
교수: 각 탭의 html 주소와 실제 이름이 맞도록.
- 파일 이름(곧 주소)을 탭 이름에 맞췄다: `students` → `lab-members`, `mentees` → `other-mentees`, `research` → `overview`, `publications` → `list`, `landscape` → `map`, `teaching` → `courses`. 이미 맞던 것(`faculty`, `seminar`, `funding`, `talks`, `contact`)은 그대로.
- 옛 주소 여섯 개는 리다이렉트 파일로 남겼다. 외부(CV, 개인 사이트, Paper Stella 공개판)의 링크가 깨지지 않고, `research.html#perception` 처럼 # 뒤 위치도 넘긴다.
- 주소를 가리키던 곳: `_config.yml` 메뉴, `index.md`·`overview.md` 링크, `seminar.html` 멤버 링크, 페이지 body class(`page-lab-members` 등)를 쓰는 `theme.css` 선택자, `page-design.json`·`page-design.md`, 검사 스크립트(`check_postech`, `check_interaction`, `check_selection`, `test_design`, `test_font_evidence`), 참고용 옛 테마 두 개.
- `AGENTS.md`: 파일 지도, 리다이렉트 목록, "파일 이름은 탭 이름을 소문자·하이픈으로" 규칙.

### 기각한 안과 이유(4차)
- 하위 폴더 주소(`publications/map.html`): 사이트의 링크와 그림 경로가 전부 상대 경로라 폴더가 생기면 모두 고쳐야 한다.
- 각 메뉴의 첫 탭은 메뉴 이름 주소로 두기(`publications.html` = List): 탭 이름과 주소를 맞춘다는 요청과 어긋난다.
- 파일 이름은 두고 `permalink` 로 주소만 바꾸기: 파일과 주소가 갈려 다음 사람이 헷갈린다.
