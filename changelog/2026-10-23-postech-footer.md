> **한줄 결론: 전 페이지에 POSTECH 소속 랩 사이트 표준 꼬리말을 새로 달아, POSTECH 대표홈·연구실 홈·학과 링크와 개인정보취급처리방침·주소·POSTECH 로고를 넣었다.**

## 요청

정보기술팀 남단비 선생님이 2026-09-15 메일로 보낸 홈페이지 디자인 권장사항(moai.postech.ac.kr 도메인 연결 전 선행 조건, 2026-10-22 메일에서 재확인)을 반영. 메일 첨부 안내 이미지(`모상우교수님 안내.jpg`)의 코멘트 5개가 근거다. 원본 첨부는 저장소 밖 `academic-profile/_backup/moai-site-danbinam-design-2026-09-15/` 에 백업했다.

코멘트와 이 사이트 반영:
- ① 대표홈페이지 링크(`https://www.postech.ac.kr/kor/index.do`) → 꼬리말 POSTECH 로고에 적용
- ② 홈페이지 홈 링크 → 꼬리말 `MOAI Lab` 글자(머리글 로고는 이미 홈 링크)
- ③ 개인정보취급처리방침 텍스트 링크(`.../usage-guide/privacy_policy.do`) → 꼬리말 하단
- ④ POSTECH 하단 로고 → 대표홈 링크(첨부 `POSTECH-en.png` 사용)
- ⑤ 학과·연구실 로고와 홈링크 → 학과(IME) 링크 + `MOAI Lab` 홈 링크

## 반영 내역

- `includes/footer.html`: 빈 자리였던 꼬리말을 다시 썼다. 윗줄에 `MOAI Lab`(홈)·학과(IME) 링크·주소, 오른쪽에 POSTECH 로고(대표홈). 아랫줄에 저작권과 개인정보취급처리방침. 이메일은 넣지 않았다(사이트 표기 규칙: 가린 형태만, mailto 금지).
- `layouts/default.html`: `{% include footer.html %}` 를 `<main>` 뒤에 추가. 강의 사이트(`course.html`)는 자체 꼬리말이 있어 건드리지 않았다.
- `theme.css`: `.site-foot` 등 꼬리말 스타일을 전역 토큰으로 추가(밝은 배경, Pretendard, 평소 본문색 링크·hover 때만 강조). `.wrap` 을 flex 세로 + `min-height:100dvh`, `main` 을 `flex:1` 로 바꿔 짧은 페이지(404 등)에서도 꼬리말이 화면 맨 아래에 붙게 했다. 본문 끝 여백은 `--space-9`→`--space-8`(꼬리말이 생겨 과한 여백을 줄임).
- `assets/img/postech-logo.png`: 첨부 `POSTECH-en.png`(공식 영문 로고, 267×67 RGBA).
- 검증: jekyll 4.4.1 로 전 페이지 빌드, 13개 본문 페이지 모두 꼬리말·개인정보방침 링크 출력 확인, 강의 2개 페이지는 미출력 확인. 데스크톱·375px 모바일·짧은 404 페이지를 브라우저로 눈으로 확인.

## 기각한 안과 이유

- 예시안(CSL 랩)의 어두운 회색 표준 꼬리말을 그대로 재현: 교수 결정으로 기각. 현재 사이트의 밝고 미니멀한 톤과 대비가 커서, 경량 꼬리말로 같은 정보를 담기로 함.
- 머리글 좌상단에 POSTECH 심볼/워드마크 추가(코멘트 ①의 엠블럼): 교수 결정으로 기각. 첨부에 원형 엠블럼 파일이 없고 머리글을 미니멀하게 두기로 해, POSTECH 대표홈 링크는 꼬리말 로고(④)로 충족.
- 꼬리말 POSTECH 로고로 `POSTECH8.png`(마젠타 워드마크, 118×10): 해상도가 낮아 기각. 공식 전체 로고 `POSTECH-en.png`(267×67) 사용.
- 백업 첨부를 저장소 `_backup/` 에 커밋: 공개 저장소에 교수 사진·내부 안내가 들어가 기각. 저장소 밖 `academic-profile/_backup/` 로 옮김.

## 추가 반영 (2026-10-23, 2차)

- **⑤ 연구실 로고 완성**(교수: "디자인 수정사항은 다 반영해야지"): 꼬리말 `MOAI Lab` 글자 앞에 사이트 로고 마크(`logo-mark.svg`)를 머리글 브랜드와 같은 양식으로 넣어 연구실 로고를 시각적으로도 표시. 홈 링크는 그대로. 학과(IME)는 로고 파일이 없어 텍스트 링크 유지.
- **짧은 페이지 탭 늘어남 버그 수정**(교수 지적: "teaching 탭 부분 망가진듯"): 1차에서 sticky 꼬리말을 `main { flex: 1 }` 로 만들었더니, 내용이 짧은 페이지(Teaching Courses 등)에서 `main` 그리드가 세로로 늘어나 Courses/Talks 서브내비 알약이 빈 채로 길어졌다. `main` 늘림을 빼고 `.site-foot { margin-top: auto }` 로 바꿔(표준 sticky 패턴) 그리드를 늘리지 않으면서 꼬리말을 화면 맨 아래에 붙게 했다.

## 추가 반영 (2026-10-23, 3차: 꼼꼼 검토 후)

교수 요청("확실해? 꼼꼼하게 검토해줘", "포스텍 연결은 kor 말고 eng로")으로 live 18개 페이지를 데스크톱 1280px·모바일 375px 에서 재고(가로 넘침 없음, 하위 탭 높이 35px 고정, 꼬리말이 문서 맨 아래), 안내 이미지와 저장소 규칙을 다시 대조했다. 안내 이미지는 그때 도메인이 가리키던 교수 개인 Google Site 화면에 단 주석이고, 교수 의도는 그 피드백을 이 연구실 사이트에 옮기는 것이다.

- 꼬리말 내용(학과, 주소, 전화, POSTECH·개인정보 링크)을 `footer.html` 에서 `_config.yml` 의 `footer` 로 옮겼다. 테마에 콘텐츠를 박아 둔 것이 "테마는 콘텐츠를 담지 않는다" 규칙에 어긋났다. 옛 값 `footer: MOAI Lab, POSTECH` 는 어디서도 쓰지 않아 대체.
- POSTECH 대표홈과 개인정보 링크를 영어판(`/eng/index.do`, `/eng/usage-guide/privacy_policy.do`)으로 바꿨다. 링크 이름은 영어판 본부 꼬리말의 공식 명칭 `Personal Information Policy` 로 하고, 본부처럼(`class="str"`) 굵게 해 다른 고지와 구분했다.
- `AGENTS.md`: 테마 계약에 `includes/footer.html` 필수 요소와 sticky 방식을 적고, 구분선 규칙("남은 선은 메뉴 아래 하나")에 꼬리말 두 줄을 더하고, 주소·전화를 "같은 내용은 한 곳에만"의 예외로 적었다.

기각한 안: 링크 이름을 안내문 표기 "개인정보취급처리방침" 그대로 두기. 링크가 영어 페이지로 가고 사이트도 영어라, 대상 페이지의 공식 영문 명칭과 맞췄다. 한국어판(`/kor/`) 링크는 교수 요청으로 기각.

## 추가 반영 (2026-10-23, 4차: 머리글 POSTECH 로고, 강의 페이지)

교수 요청: "머리글 좌상단 POSTECH 로고(영어판 대표홈 링크)와 강의 페이지 꼬리말의 POSTECH·개인정보 링크까지 반영". 안내 이미지 ①(옛 Google Site 머리글 좌상단 POSTECH 엠블럼을 대표홈에 링크)을 글자 그대로 따른다.

- `header.html`: 좌상단에 POSTECH 워드마크(영어판 대표홈 링크)를 두고 그 오른쪽에 연구실 로고·이름(홈 링크, ②). 워드마크는 첨부 공식 로고 `POSTECH-en.png` 에서 "POSTECH" 글자 줄(264×26, 색 그대로)만 잘라 `assets/img/postech-wordmark.png` 로 만들었다. 높이 16px.
- `theme.css`: 로고가 늘어 700~970px 폭에서 메뉴가 두 줄로 접히는 것을 재서 찾았다(바꾸기 전에는 한 줄). `.site-head` 에 `flex-wrap` 을 줘 그 폭에서는 메뉴 전체가 아랫줄 한 줄로 내려가게 했다. 1280px 머리글 높이(88px)와 위치는 그대로.
- `layouts/course.html`, `course/course.css`: 강의 사이트 바닥 한 줄의 링크 없던 `POSTECH` 글자를 영어판 대표홈 링크로 바꾸고, 같은 줄 오른쪽 끝에 개인정보 링크(굵게)를 더했다. "바닥 한 줄" 결정(2026-10-22)은 유지.
- `_config.yml`: 세 곳이 같이 쓰는 POSTECH 값(대표홈, 워드마크, 로고, 개인정보 링크)을 `postech` 블록 하나로 모으고, `footer` 에는 학과·주소·전화만 남겼다.
- `AGENTS.md`, `course/README.md`: "POSTECH 필수 요소" 항목으로 머리글·꼬리말·강의 바닥의 필수 요소를 적었다.
- 확인: 본문 13개 페이지 머리글·꼬리말과 강의 6개 페이지 바닥에 영어판 링크가 있는지 빌드 결과로 확인. 1280·961·700·375px 에서 머리글 측정(1280 한 줄 88px, 961·700 메뉴 아랫줄 한 줄, 375 로고 한 줄), 전 페이지 가로 넘침 없음, 하위 탭 35px, 꼬리말 맨 아래.

기각한 안: 첨부 `POSTECH8.png`(마젠타 워드마크) 그대로 쓰기. 118×10 이라 16px 로 키우면 흐리다. 원형 엠블럼은 첨부에 없어 쓰지 않았다. 머리글의 두 로고 사이에 세로 구분선 넣기: 구분선 최소 규칙에 따라 간격으로만 나눴다. 960px 아래 새 breakpoint 로 머리글을 두 줄로 바꾸기: 폭 계산에 따라 자동으로 내려가는 `flex-wrap` 이 로고·메뉴 길이가 바뀌어도 맞는다.
