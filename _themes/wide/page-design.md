# 페이지별 디자인 검토

기본 템플릿을 먼저 적용하고, 정보량·배치·중요도에 따라 필요한 부분만 조정한다. 이 문서는 `page-design.json`에서 생성한다. 변경 뒤 `node tools/check_design.js --write-review`로 갱신한다.

## 공통 기본값의 가독성 조정

| 대상 | 조정 | 근거 |
| --- | --- | --- |
| 상단 1차 메뉴 | 14px → 본문 크기 16px, 모든 항목 600 유지 | 상시 탐색하는 짧은 라벨이므로 논문 보조정보보다 크게 표시. 탭 이동 후 위치·폭은 유지. |
| 드롭다운 하위 메뉴 | Faculty·Members 등 600→400, 크기16px 유지 | 상단 1차 메뉴와 같은 강조 굵기가 상속돼 하위 항목이 무겁게 보임. 하위 탐색은 보통 굵기로 구분하고 hover 표시 유지. |
| 하위 탭·헤더 동작 링크 | 14px → 전용 control 크기 15px | 내용을 읽는 보조 글자와 실제 탐색 동작을 구분. 16px은 좁은 필터 줄을 불필요하게 자주 접어 15px 선택. |
| 스터디 학기 탭 | 학기 14→16px, 주제 13→14px | 학기는 일정 선택의 주 정보이며 두 열 모바일 배치에 여유가 있음. 주제는 한 단계 작게 유지. |
| 운영 정보 | 교수·TA·시간·장소 14→16px, 인물 보조 설명 13→14px | 강의·스터디 운영 정보는 방문자가 직접 찾아야 할 핵심 정보. 사진과 패널의 여백을 이용해 본문 크기로 표시. |
| 초청 연사 이름 | 14px → 본문 크기 16px | 발표자를 식별하는 주 정보. 팀 구성원 전체 목록·참고문헌과 구분하고 600 강조는 유지. |
| 랩·스터디·강의 헤더 | header-brand.html 정본과 site-head·공통 탐색 스타일 사용. PC 88px, 태블릿 115px, 모바일 163px 높이. 모바일 메뉴는 같은 3열·2행 슬롯 사용. | 페이지를 오갈 때 좌상단 학교·연구실 로고 높이와 탭 위치가 달라지지 않게 함. 강의는 같은 위치에 과목명으로 대체. 320px에서도 공식 워드마크 비례와 긴 과목명 유지. |

## 페이지별 조정

| ID | 페이지 | 조정 | 근거 |
| --- | --- | --- | --- |
| student-card-reading | `students.html` | 학력·소속·연구 주제 14→16px. 이름 19/18px와 사진 배치 유지. | 사진 카드의 학력과 소속은 사람을 이해하는 핵심 정보이며 주변 여백이 넓다. 논문 목록의 보조정보 크기를 그대로 적용하면 작게 보인다. |
| faculty-contact-reading | `faculty.html` | 연락처와 프로필 링크 14→16px. CV의 연도·상세 설명은 14px 유지. | 사진 옆 연락처는 독립된 짧은 정보 블록이고 실제로 찾아 눌러야 한다. 긴 CV 목록의 보조 연도와 동일 크기로 묶지 않는다. |
| mentee-affiliation-reading | `mentees.html` | 멘티 학위·소속 14→16px. 오른쪽 논문·연도는 14px 유지. | 학위와 소속은 멘토링 관계를 설명하는 주요 내용이다. 간단한 행 구성이므로 본문 크기로 읽히게 하고 성과 표시는 보조 크기로 남긴다. |
| research-card-reading | `research.html` | 주제 설명 14→16px. 논문 칩의 약칭·venue는 14/13px 유지. | 넓은 한 열 카드의 설명 문장은 연구 방향을 이해하는 본문이다. 세 열의 강의 요약 카드나 논문 칩과 달리 읽기 공간이 충분하다. |
| teaching-term-navigation | `teaching.html` | 학기 이동 링크 14→15px. 학수번호는 14px 유지. | 학기는 단순한 날짜가 아니라 해당 강의로 이동하는 선택지다. 짧은 강의 목록의 오른쪽 여백에 맞춰 한 단계 크게 표시. |
| seminar-speaker-reading | `seminar.html` | 연사 이름 14→16px. 소속·날짜 14px, 제목 16px 유지. | 연사가 발표 목록의 핵심 정보라는 기존 결정에 맞춘다. 사람 이름은 본문 크기로 식별하고 소속·날짜만 보조 크기로 남긴다. |
