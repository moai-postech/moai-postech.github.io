- `_data/ai_study_terms.yml`: `spring-2027`(cohort 4, tldr, learning_path 3단계, advisor). meetings·location·representative 는 미정이라 두지 않아 운영 정보 줄에는 Advisor 만 보인다. 새 칸 `upcoming: true`, `demo_heading: "Game"`.
- 이번 학기 판정: `study.html`, `study-overview.html`, `study-schedule.html` 이 `ai_study.yml` 첫 학기 대신 `upcoming` 이 아닌 가장 최신 학기를 이번 학기로 쓴다. Home 버튼·학생대표 링크·Now·Schedule 기본 탭이 Fall 2026 그대로다. Spring 2027 은 Home 타임라인에서 Now 뒤 점선과 `Next` 표시로 보인다. 학기가 시작되면 `upcoming` 줄만 지운다.
- `study-schedule.html`: Demo 열 머리와 카드 라벨을 `demo_heading` 으로 바꿀 수 있게 했다. 열 순서와 위치는 모든 학기가 같다(1440px 에서 다섯 학기 열 좌표 일치 확인).

## 기각한 안과 이유
- Spring 2027 을 시트에서 Fall 2026 아래에 두어 "첫 학기 = 이번 학기"를 유지: 시트와 사이트 모두 최신 학기가 위라는 규칙을 깨고, 학기가 시작될 때 시트 행을 옮겨야 한다.
- 이번 학기 ID 를 파일 맨 위 전역 칸(`current: fall-2026`)으로 두기: 학기 ID 를 키로 읽는 파일에 학기가 아닌 키가 섞이고, 새 학기마다 두 곳(전역 칸, 학기)을 고쳐야 한다.
- 미정 칸을 `To be announced` 로 채우기: 데이터에 값이 아닌 문구를 넣게 되고, 빈 칸을 생략하는 기존 규칙(`facts.html`)으로 깨지지 않는다.
- Demo 열을 새 Game 열로 따로 두기: 다른 학기와 열 순서가 달라진다. 머리만 바꾸는 것은 `format: lectures` 의 Papers→Lectures 와 같은 방식이다.
