## 요청과 결정
- 교수는 게스트 강의가 불균형해 보인다며 연사와 제목 순서를 바꾸고 시간·장소를 두 줄로 나누는 디자인 검토와 공통 양식 확정을 요청.
- 공개 frontend-design 스킬의 정보 위계·정렬·실제 화면 검토 절차 적용. 기존 글꼴·팔레트·스티커와 토큰 유지.
- 기존 양식의 제목 아래 좌우로 흩어진 정보 대신, 왼쪽은 연사·소속 → 제목, 오른쪽은 시간 → 장소의 두 묶음을 위쪽부터 정렬.

## 반영 내역
- Guest lecture·Department seminar 공통 템플릿 수정. 연사16px·600, 소속14px·400, 제목16px·400으로 역할을 구분.
- 제목·시간·장소가 없는 경우 해당 줄을 만들지 않고, 자료가 있는 경우 기존 Materials 열 유지.
- 960px 이하에서는 시간·장소를 본문 아래에 왼쪽 정렬. 긴 한글 제목과 장소를 자연스럽게 줄바꿈.
- 공통 디자인 계약에 강연 제목 역할을 등록하고 강의 양식·페이지별 검토 근거 갱신.
- 전체 검사에서 앞선 Teaching 홈 링크 요청과 충돌하는 과거의 '소개 링크 없음' 검사를 발견. 해당 링크의 목적지·주변 글자색·드래그·일반 클릭을 검증하도록 갱신.
- 원본 복구 경로: Git `81f3330`.

## 기각한 안과 이유
- 기존 제목 우선·그 아래 연사와 운영 정보 가로 배치: 읽는 축이 흩어지고 이름과 제목의 위계가 약함.
- 모든 정보를 한 줄에 강제: 긴 제목·소속·장소에서 폭이 부족함.
- 별도 색·글꼴·카드 장식 추가: 일정표의 정보 정렬만으로 해결 가능.
