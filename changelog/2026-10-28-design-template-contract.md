# 2026-10-28 공통 디자인 템플릿 계약
작성자: Sangwoo Mo(sangwoomo) | 대상: 공통 테마·강의 템플릿·디자인 검사 | 도구: Codex

> **한줄 결론: 공통 템플릿을 기본으로, 페이지별 가독성 조정과 근거를 기록하고 함께 검사.**

## 요청
- 교수는 페이지별 땜질 대신 공통 템플릿을 먼저 정하고 전수 검토하도록 요청.
- 상단 탭은 다른 탭으로 이동해도 메뉴와 위치를 일관되게 유지하도록 추가 요청.
- 글자 크기가 작아졌는지도 확인 요청.

## 결정과 반영
- 상세 역할표를 `_themes/wide/README.md`로 옮기고 `design-contract.json`에 역할별 selector·속성·화면 폭 명시.
- 굵기 400·600·700을 공통 토큰으로 고정. strong을 브라우저 기본값에 맡기지 않음.
- 묶음 제목은 템플릿의 group-heading 역할로 지정. 페이지 이름과 글자 크기로 역할을 추측하던 코드 제거.
- 카드 제목 행간·자간, Research 절 제목 행간, 강의 현재 메뉴의 굵기, All news의 마감 안내 역할을 공통 규칙에 맞춤.
- 새 페이지 자동 발견, 모든 탭·필터·메뉴·펼침 상태, 역할별 크기·굵기·색·여백·본문 폭·표 마감선 검사 추가.
- CI에서 디자인 계약과 회귀검사를 실행하고 JSON 측정 결과 보관.
- 상단 메뉴는 모든 항목 600으로 고정하고 현재 탭은 색·밑줄로만 표시. 같은 문서 틀의 페이지 사이에서 메뉴 항목·순서·좌표·폭 비교.
- 최신 Study Home의 Schedule 링크도 헤더 동작 역할로 통일. 링크 클래스명이 달라도 헤더 슬롯의 동작이면 검사하도록 보강. 스터디 파트 선택 버튼도 선택 컨트롤의 600 굵기를 따름.

## 글자 크기 확인
- 이전 변경 e3bb954에서 교수 요청으로 보조 15→14px, 본문 17→16px, 묶음 20→19px, 절 제목 28→26px, 큰 제목 34–48→32–46px로 축소. 작은 글자는 13px 유지.
- 이번 검토에서는 해당 공통 크기를 유지하며 임의로 복원하지 않음.
- 동시 반영된 venue의 600 강조는 publication-venue 역할로 분리해 보존. metadata wrapper·자료 링크의 400과 구분하고 로고 후속 변경도 보존.

## 기각한 안과 이유
- 페이지마다 보이는 부분만 수정: 다음 수정에서 같은 불일치 재발.
- CSS 결과의 글자 크기로 제목 역할 추측: 잘못된 역할이 검사에서도 그대로 통과할 수 있음.
- 모든 링크를 동일하게 bold 처리: 탐색·자료 동작과 문장 속 안내의 역할 차이를 지움.
- 자동 검사 통과만으로 시각 검토 완료 보고: 실제 PC·모바일 렌더 비교가 별도로 필요.

- 기존 형식·타이포그래피·드래그·조작·POSTECH 검사 통과. 모든 페이지의 PC·모바일 렌더 비교.
- 원본 복구: Git 7293012 및 이번 변경 전 원격 main. 콘텐츠·로고·개인정보 보호 작업은 기존 커밋을 보존.

## 1차 검증
- 최신 원격 main 4ace89a의 글자 크기·venue·로고·스터디 변경을 보존해 통합.
- Jekyll 빌드 성공. 디자인 계약 26페이지·49역할·7폭·616상태에서 위반 0건.
- 상단 메뉴는 같은 문서 틀의 페이지 사이에서 항목·순서·좌표·폭이 일치. 모든 메뉴 항목의 굵기 600, 현재 상태는 색·밑줄만 변경.
- 형식 14페이지×5폭, 타이포그래피 26페이지·192상태·19,697텍스트·제목 경계18조합, 선택16건, 조작26페이지×2폭, POSTECH26페이지×2폭 통과. 기존 스터디 개인정보 검사도 통과.
- 실제 개인정보 대신 가상 암호문으로 동일 명단 UI를 열어 잠금 해제·재잠금 상태의 디자인 검사.
- 모든 페이지의 PC·모바일 기본 렌더와 공통 컴포넌트 상세 비교. 스터디 Schedule 링크와 파트 선택 버튼의 누락도 공통 동작 역할로 수정.
- 글자 크기는 본문16px·보조14px·작은 글자13px로 이전 축소 결정을 유지.
- CI는 매 변경에 동일 계약을 실행하고 design-audit JSON을 보관. 새 페이지 자동 발견, 클래스명과 무관한 헤더 슬롯의 동작 링크 검사.
- 실측 원본은 세션 scratch의 moai-template-final-audit.json. 이후 CI design-audit 산출물에서 재현 가능.

## 반영 대기
- 자동 승인 검토가 main 직접 push를 거부: 여러 페이지에 적용되는 공개 사이트 변경이며 이번 규모의 main 배포에 명시적 승인이 없다는 사유.
- 안전한 대안으로 검토용 PR을 준비. 배포 승인 전에는 main에 반영하지 않음.

## 후속 검토: 템플릿 + 페이지별 필요한 조정
- 교수는 상단 메뉴와 멤버의 BS, POSTECH 같은 글자가 너무 작아졌음을 지적. 글자 양과 배치가 다른 HTML을 기계적으로 같은 크기에 맞추지 말고, 템플릿을 기본으로 필요한 조정의 왜·어떻게를 남기도록 요청.
- 이 요청에 따라 페이지별 조정을 금지하던 AGENTS.md·템플릿 규칙을 교체. 기본 역할과 등록한 페이지 조정을 함께 검사하도록 변경.
- 상단 메뉴14→16px, 하위 탐색·헤더 동작14→15px. 상단 항목·순서·좌표·폭 유지 검사는 그대로 적용하며 페이지별로 상단 메뉴를 다르게 만들 수 없음.
- 멤버 학력·소속·연구 주제14→16px. Faculty 연락처·프로필 링크, 멘티 학위·소속, Research 설명, Seminar 연사도 정보 중요도·공간에 따라16px. Teaching 학기 이동은15px. 각각 별도 조정과 이유 등록.
- 강의·스터디 운영 정보14→16px, 학기 탭16/14px, 파트 선택14px. 긴 일정 표·논문 목록의 보조정보14px·표 머리13px는 밀도와 위계 때문에 유지.
- 원본 `_themes/wide/page-design.json`에26개 페이지의 기본 유지/조정 판단과 근거 기록. 사람이 읽는 `page-design.md`는 원본에서 생성해 중복 결론의 어긋남 방지.
- 새 페이지 자동 발견은 유지하고 해당 화면의 검토 근거가 없으면 실패. 등록한 조정을 기본 크기로 되돌려도 실패하도록 멤버 학력의14px 회귀 주입 테스트 추가.
- 중복된 폰트 강제 검사는 공통 디자인 검사로 모음. 기존 형식·타이포그래피 검사는 여백·잘림·최소 가독성 등을 계속 확인.
- 재검증:54개 기본 역할 +6개 페이지 조정,26페이지·7폭·616상태 통과. 형식14페이지×5폭·타이포그래피26페이지192상태·19,697텍스트, 드래그·조작·학교 요소·명단 보호 검사 통과. PC·모바일의 멤버·상단 메뉴·교수 정보·연사 표를 렌더 비교.
- 기각: 모든 보조정보를14px로 통일. 사진 카드의 핵심 정보와 긴 논문 목록의 보조정보는 읽는 목적과 공간이 달라 같은 크기를 강제하지 않음.
- 남은 action은 기존PR의 최종 main 반영 승인. 검토와 수정은 동일PR에 갱신.

- 최종 통합 시 원격4e8ebd4의 모바일 여백 축소·메타 그룹16px·로고 복원도 보존. 콘텐츠 양에 맞춘 기존 모바일 여백 조정을 이번 폰트 가독성 보정으로 되돌리지 않음.
