## 추가: Slides 자리 표시(같은 날)
교수: "slides도 placeholder 만들어놔야지". 자료가 하나도 없어 Spring 2027 표의 Slides 머리와 칸이 비어 있었다.
- `study-schedule.html`: 학기에 자료가 하나도 없으면 Slides 칸(머리 `Slides`, 폭은 `PDF`)을 그대로 만든다. `upcoming` 학기는 슬라이드 없는 회차에 링크 없는 회색 `PDF`(`.st-pending`, 화면 읽기 프로그램에는 숨김)를 둔다. 시트는 고치지 않았고, 동기화로 링크가 들어오면 그 회차만 진짜 `PDF` 로 바뀐다.
- `course.css`: `.st-pending` 은 본문 보조색(`--muted`). 960px 이하 카드에서는 자리 표시 칸을 숨긴다(빈 `PDF` 라벨처럼 보였다).
- 확인: 로컬 빌드에서 1440px 다섯 학기 머리 좌표 일치, 다른 네 학기 표 HTML 이 수정 전과 글자 단위로 같음, 800px·375px 가로 넘침 없음.
- `STUDY.md` 에 규칙을 적었다.

## 기각한 안과 이유
- (Slides 자리 표시) 시트 Slide 칸에 임시 링크나 빈 PDF 를 넣기: 학생이 올린 진짜 파일과 섞이고 동기화가 가짜 파일을 사이트에 올린다.
- (Slides 자리 표시) 강의 스케줄처럼 머리만 두고 칸은 비우기: 열이 비어 보여 "placeholder" 요청에 못 미친다.
- (Slides 자리 표시) 모든 학기의 빈 회차에 회색 PDF: 지난 학기에 원래 없던 자료가 곧 올라올 것처럼 보이고 다른 학기 화면이 바뀐다.

- Spring 2027 을 시트에서 Fall 2026 아래에 두어 "첫 학기 = 이번 학기"를 유지: 시트와 사이트 모두 최신 학기가 위라는 규칙을 깨고, 학기가 시작될 때 시트 행을 옮겨야 한다.
- 이번 학기 ID 를 파일 맨 위 전역 칸(`current: fall-2026`)으로 두기: 학기 ID 를 키로 읽는 파일에 학기가 아닌 키가 섞이고, 새 학기마다 두 곳(전역 칸, 학기)을 고쳐야 한다.
- 미정 칸을 `To be announced` 로 채우기: 데이터에 값이 아닌 문구를 넣게 되고, 빈 칸을 생략하는 기존 규칙(`facts.html`)으로 깨지지 않는다.
- Demo 열을 새 Game 열로 따로 두기: 다른 학기와 열 순서가 달라진다. 머리만 바꾸는 것은 `format: lectures` 의 Papers→Lectures 와 같은 방식이다.
