## 요청과 결정
사용자가 Google API를 알아서 사용해 최종본을 만들도록 요청했다. 기존 스케치 유지와 얼굴 유사성 개선 범위는 [전날 기록](2026-11-06-home-photo-original.md)을 따른다.

## 반영 내역
- 저장된 GEMINI_API_KEY를 요청 헤더에 사용했다. 키 값을 출력하거나 파일에 복제하지 않았다. Google 모델 목록 API로 사용 가능한 `gemini-3-pro-image`(Nano Banana Pro)를 확인했다.
- 원본 사진과 현재 스케치의 얼굴을 네 명씩 2×2 확대판으로 구성했다. Google REST generateContent API에 입력 두 장, 출력 TEXT·IMAGE, 3:4·2K 설정으로 호출했다.
- 스케치를 편집 대상으로 한 방식과 원본 사진을 직접 그리기 기준으로 한 방식을 각각 앞·뒤 네 명에 적용했다. 총 네 번 호출했고 각 호출에서 이미지 한 장을 받았다.
- 원본 직접 변환안은 일부 인물의 입 모양·표정 변화가 더 커서 제외했다. 첫 방식이 기존 색연필 질감과 원본 인상을 더 안정적으로 유지한다고 판단했다. Google이 모든 얼굴을 원본과 정확히 같게 만든다는 의미는 아니다.
- 선택한 Google 그림의 머리 부분만 좁은 마스크로 현재 스케치에 반영했다. 사진 얼굴을 붙이지 않았다. 최종 PNG 1732×908 크기와 머리 마스크 밖의 모든 픽셀 일치를 검사했다. 배경·몸·옷·손동작·전체 배치는 그대로다.
- 최종 파일은 `assets/img/lab/group-2026-sketch-google.png`다. 기존 스케치와 앞선 얼굴 수정본은 보존했다. Home 이미지 참조와 캐시 버전, AGENTS.md의 운영 이미지 기준을 갱신했다.
- 입력·출력·두 방식의 프롬프트·모델 ID·사용량·검증 해시와 재현 스크립트는 로컬 `visual-review-bundle/google-faces/`에 보관했다. `generate.py`, `generate-photo-first.py`, `prepare.py`, `assemble.py`, `metadata-*.json`, `verification.json`을 참조한다.

## 기각한 안과 이유
- 원본 사진을 직접 변환한 Google 안: 일부 표정 변화가 커서 기존 스케치에서 얼굴을 수정한 안을 선택했다.
- 전체 그림 재생성: 얼굴 외 요소도 바뀔 수 있어 머리 영역만 반영했다.
- 기존 GPT 수정본 그대로 유지: 사용자가 Google API 결과로 최종본을 만들도록 요청했으므로 실제 Google 호출 결과를 적용했다. Google 결과가 모든 기준에서 우월하다고 주장하지 않는다.

## 실제 인상과 가벼운 미화를 함께 개선
- 사용자 목표: Google API로 더 예쁘면서 실제 사진과 비슷한 최종본. 가벼운 미화는 허용한다.
- 앞선 네 명씩의 참조 대신 각 인물의 원본 사진과 현재 스케치 한 장씩을 개별 입력했다. `gemini-3-pro-image`에 3:4·1K 설정으로 여덟 번 호출했고, 여덟 결과 모두 정상 종료와 이미지 반환을 확인했다.
- 원본 얼굴형·눈매·안경·코·입·머리·표정을 유지하며 부드러운 빛·고른 피부톤·자연스럽고 명료한 눈·섬세한 연필선을 요청했다. 큰 눈·슬림한 턱·새 미소·과한 미화는 제외했다.
- 원본·이전·개선 스케치의 여덟 얼굴을 같은 위치로 확대해 비교했다. 개별 참조에서 얼굴 세부와 선이 더 또렷해졌고, 표정과 피부 표현도 자연스럽게 정리됐다고 판단했다. 원본과 완전 일치를 뜻하지 않는다.
- 일부 결과의 피부가 주변보다 지나치게 밝아 피부 영역의 중앙값을 기준으로 채널별 0.94~1.04 범위의 약한 색 변환을 적용했다. 이 단계는 형태를 바꾸지 않는다.
- 머리 영역만 기존 그림에 반영했다. 마스크 밖의 픽셀은 모두 기존 운영 이미지와 같고 해상도도 1732×908로 동일하다. 배경·옷·몸·M 손동작·구도는 유지했다.
- 최종 파일은 `assets/img/lab/group-2026-sketch-refined.png`다. 기존 파일은 보존했다. Home 이미지 참조·캐시 버전과 AGENTS.md의 현재 파일 및 가벼운 미화 범위를 갱신했다.
- 입력·개별 Google 응답 이미지·프롬프트·모델과 사용량·검증 해시·실행 스크립트·비교판은 로컬 `visual-review-bundle/google-refined/`에 보관했다. `likeness-comparison.jpg`, `verification.json`, `generate.py`, `assemble.py`를 참조한다.
- 기각: 네 명을 함께 수정하는 기존 방식은 개별 특징의 추가 개선이 작았다. 생성 결과를 그대로 붙이면 일부 얼굴의 피부가 너무 밝다. 전체 그림을 다시 만들면 기존 스케치의 장점이 바뀐다.
- 검증: 위의 원본·이전·개선 비교와 전체 이미지 검토, 머리 밖 픽셀 일치·이미지 크기·여덟 API 응답을 확인했다. 기존 규칙과 secrets.md를 따랐고 Jekyll 빌드, Home 화면, push 훅, 해당 GitHub 검사·배포와 공개 파일 일치를 확인한다.


## 사용자 반려: 유사성과 미화 모두 불충분
- 사용자는 개선본이 실제 인물과 닮지 않고 더 보기 좋아졌는지도 모르겠다고 지적했다. 앞선 자체 검수의 개선 판단을 철회한다. 현재 홈페이지 사진은 그대로 두고 후속 시험은 게시하지 않았다.
- 기존 스케치 얼굴을 반복 참조하면서 이미 달라진 얼굴 특징을 이어받았을 가능성을 확인했다. 얼굴이 없는 나뭇잎·옷·종이 질감만 스타일 참조로 분리하고 원본 사진만 인물 기준으로 사용했다.
- 두 인물을 대상으로 Google Pro와 Flash에서 각각 시험했다. Pro는 첫 인물의 머리와 눈 형태가 원본 쪽으로 달라졌으나 피부가 너무 희고 푸르다. 다른 인물의 안경은 여전히 커졌다. Flash는 표정·안경·머리가 더 달라져 제외했다. 닮음과 미화 두 기준을 모두 만족했다고 판단하지 않는다.
- 비교판 `visual-review-bundle/google-faithful/comparison-two-faces.jpg`에 원본·현재 홈페이지·Pro·Flash를 같은 크기로 배치했다. 프롬프트·API 응답 정보와 결과는 google-faithful/·google-faithful-flash/에 보관했다.
- 로컬에서 확인한 원본은 웹용 2000×1333 JPEG와 크롭된 1780×933 JPEG다. 인물 얼굴은 약 100px 크기다. 기록상 고해상도 원본 이름은 `0904_MOAI_단체사진_5.jpg`다. Google Drive 스킬로 MOAI Lab 폴더와 관련 경로·파일명을 검색했으나 원본 파일을 찾지 못했다. 다른 행사 사진은 내려받지 않았다.
- 남은 것: 고해상도 원본의 위치 확인, 원본 인물 유사성 및 자연스러운 미화 재검수. 이번 시안은 운영 이미지에 적용하지 않았다. 사용자의 평가 없이 개선 완료라고 보고하지 않는다.


## 방향 재확인: 알아보이는 얼굴에 자연스러운 인물화 보정
- 사용자: 닮은 상태에서 좀 더 잘생기고 예쁜 느낌이 가장 좋다고 설명했다. 고해상도 원본을 새로 요청하기보다 기존 자료로 얼굴의 표현을 보정하는 방향으로 진행했다.
- 원본 사진을 다시 그리며 미화하는 시험은 안경 없는 첫 인물에 안경을 추가하고 둘째의 눈을 크게 만들어 제외했다. 결과와 프롬프트는 `visual-review-bundle/google-flattering/`에 보관했다.
- 기존 스케치 얼굴을 편집 대상으로, 원본 사진을 식별 특징 확인용으로 넣었다. Google API `gemini-3-pro-image`에 얼굴별 3:4·1K 요청을 여덟 번 보내 같은 인물의 피부·명암·연필선만 정돈하도록 했다.
- 불필요한 주름선·눈 밑과 볼의 강한 그림자·긁힌 피부 표현을 줄이고, 자연스러운 피부톤과 빛·얇은 윤곽선을 요청했다. 큰 눈·새 안경·V자 턱·새 미소·과한 화장은 금지했다.
- 먼저 만든 두 얼굴에서는 새 안경이나 과한 눈 확대가 없어 같은 방식으로 나머지 여섯 얼굴도 보정했다. 미화 강도 선호를 비동기로 물으며 나머지 작업을 진행했고, 추가 답변 전까지 이 강도로 맞췄다.
- 최종 파일 `assets/img/lab/group-2026-sketch-retouched.png`는 보정된 머리 영역만 현재 스케치에 반영한 것이다. 배경·옷·몸·손과 머리 마스크 밖의 모든 픽셀이 동일하고 해상도도 1732×908이다.
- 원본·이전 홈페이지·보정본의 여덟 얼굴을 같은 크기로 비교했다. 부드러운 피부·명암과 기존 특징 유지를 검토했다. 더 잘생기거나 예뻐졌다는 주관적 평가는 사용자의 판단을 대신해 확정하지 않는다.
- 원본 참조·편집 대상·Google 응답·프롬프트·해시·재현 스크립트·비교판은 로컬 `visual-review-bundle/google-retouch/`에 있다. `likeness-comparison.jpg`, `verification.json`, `generate.py`, `assemble.py`를 참조한다.
- Home 이미지 참조·캐시 버전과 AGENTS.md의 운영 이미지·미화 기준을 갱신했다. 고해상도 원본 대기를 적었던 TODO는 이번 방향에 따라 해소했다. 기존 이미지와 원본은 보존했다.
- 기각: 얼굴을 새로 설계하는 미화는 인상을 바꾸거나 안경·큰 눈을 추가했다. 원본에 없는 특징을 더하는 안과 미화가 거의 보이지 않는 거친 피부선 유지는 제외했다.
- 검증: 여덟 정상 Google 응답, 전체 그림과 같은 좌표의 확대 비교, 마스크 밖 픽셀 일치·동일 해상도를 확인했다. 기존 AGENTS.md·workflow.md·memory-location.md·secrets.md를 따랐다. Jekyll 빌드·Home 화면·push 훅·해당 GitHub 검사와 공개 반영을 확인한다.


## 게시 승인 대기
