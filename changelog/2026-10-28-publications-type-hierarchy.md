# 2026-10-28 Publications 글자 위계와 venue 정리
작성자: Sangwoo Mo(sangwoomo) | 대상: Publications > By Year | 도구: Codex, frontend-design 스킬

> **한줄 결론: venue 배지를 없애 제목·저자·게재 정보의 시작선을 맞추고, 제목 17px와 보조 정보 15px로 글자 위계를 정리했다.**

POSTECH 요구사항: 영향 없음.

## 요청
교수가 venue의 글꼴과 본문에서 따로 뜨는 느낌을 지적하고 디자이너 스킬로 개선을 요청했다. 교수 본인의 Publications 디자인 조정 요청을 이번 변경의 근거로 삼았다.

## 디자인 결정
- Pretendard와 기존 팔레트를 유지: 흰 바탕 #ffffff, 본문 #172b40, 보조 #596574, 강조 #a61955.
- 제목은 본문 크기 17px·600, 저자와 게재 정보는 기존 공통 보조 크기 15px·400. 새 크기나 글꼴은 추가하지 않는다.
- 한 논문은 제목, 저자, 게재 정보의 세 줄로 읽힌다. 각 줄의 왼쪽 시작선을 맞추고 venue와 자료 링크 사이는 24px로 구분한다.

## 반영 내역
- `_themes/wide/includes/theme.css`: 저자·메타 역할 토큰을 공통 보조 크기에 연결. 목록 venue의 배경·안쪽 여백·둥글기 제거, 행간 상속. 메타 그룹 사이 24px, 줄바꿈 간격 4px.
- `tools/check_format.js`: 제목과 보조 정보의 역할별 크기를 검증하도록 기존 동등 크기 조건 변경.
- `tools/check_typography.js`: venue 배경·들여쓰기와 제목 시작선 일치 검사.
- 논문 데이터·순서·번호·링크는 그대로다. Oral·Spotlight·수상 표시는 기존 강조색을 유지한다.

## 검증
- Jekyll 빌드 성공. 로컬의 기존 Ruby 3.3 gem 캐시와 Ruby 호환 shim 사용.
- 형식: 13개 페이지 × 1440·1280·768·390·320px 통과.
- 타이포그래피: 26개 페이지, 177개 상태·폭, 텍스트 19,645개 통과.
- POSTECH: 연구실 14개·강의 12개 페이지 × 1280·390px 통과.
- 실제 브라우저에서 WACV 트랙과 NeurIPS 논문 목록의 정렬·글자 위계를 확인.
- 백업: Git 이력. 다른 세션의 수정과 섞이지 않도록 원격 main 기반 별도 worktree에서 반영.

## 기각한 안과 이유
- 다른 글꼴·이탤릭 venue: 사이트 전체의 Pretendard와 달라 따로 뜨는 느낌을 키운다.
- venue를 더 진한 배지나 강조색으로 표시: 제목보다 먼저 눈에 들어와 논문 목록의 위계가 약해진다.
- 논문마다 카드·구분선·이미지 추가: 긴 논문 목록을 훑는 속도가 떨어지고 기존 넓은 목록 구조와 맞지 않는다.
