# 2026-11-18 소개 뒤 간격 24px 통일
작성자: Sangwoo Mo(sangwoomo) | 대상: `theme.css`, `README.md`, `tools/check_design.js` | 도구: Claude Code

> **한줄 결론: 페이지 소개(`.lede`)에서 첫 내용까지 간격을 새 토큰 `--intro-gap`(24px, 모든 폭)으로 사이트 전체에서 통일했다.**

POSTECH 요구사항: 영향 없음

## 요청
교수: Courses 소개와 목록 사이 세로 간격이 너무 길다. Research 탭도 같다. 디자인 관점에서 무엇이 맞을지 정해 사이트 전체에 통일감 있게 반영.

## 진단
- 실측(1280·375px, 소개가 있는 10개 페이지): 하위 탭→소개와 소개→첫 내용이 둘 다 `--page-start`(넓은 화면 48px, 휴대폰 16px)라 소개가 위아래 한가운데에 떠서 어느 쪽에도 붙지 않았다.
- 휴대폰에서는 소개→묶음 제목(16)과 묶음 제목→목록(16)이 같아 제목이 어디 속하는지 흐렸다. Other Mentees 만 32px 예외로 고쳐져 있고 Funding·Publications 는 그대로였다.

## 결정(근접성 위계)
| 간격 | 값 | 역할 |
|---|---|---|
| 상단 메뉴→하위 탭 | 32 / 16 | 그대로 |
| 하위 탭→첫 내용 | 48 / 16 (`--page-start`) | 그대로 |
| 소개→첫 내용 | **24 (`--intro-gap`, 모든 폭)** | 새로 |
| 묶음 제목→목록 | 16 | 그대로 |
| 절 사이 | 64 / 48 (`--section-gap`) | 그대로 |

소개는 아래 내용의 머리말이므로 하위 탭보다 아래 내용에 가깝고(24 < 48), 묶음 제목→목록(16)보다는 넓어 제목이 자기 목록에 붙는다.

## 반영 내역
- `theme.css`: `--intro-gap` 토큰. `.page-intro +` 의 절·삽입 화면(Paper Stella)·Overview 첫 단계(레일 위치 계산 포함)를 이 토큰으로. Other Mentees 휴대폰 32px 예외는 일반 규칙이 대신해 지움. Paper Stella 의 `min(24px, page-start)` 도 같은 토큰(휴대폰 16→24).
- `README.md` 역할표 "페이지 시작"을 나누고 "소개 뒤 첫 내용" 행을 더함. `tools/check_design.js` 가 소개 바로 뒤 블록을 `--intro-gap` 으로 검사.
- 결과 실측: 넓은 화면·휴대폰 모두 소개→첫 내용 24px(목록 글자 행간 때문에 눈에 보이는 거리는 27px 안팎). Overview 는 단계 번호 원 위치 때문에 42px.

## 기각한 안과 이유
- 소개→첫 내용 16px: 묶음 제목→목록(16)과 같아져 휴대폰에서 겪던 모호함이 넓은 화면에도 생긴다.
- 32px: 하위 탭→소개(48)와 차이가 작아 여전히 소개가 떠 보인다.
- 휴대폰은 16 유지, 넓은 화면만 24: 휴대폰의 묶음 제목 모호함이 남고 Other Mentees 예외를 계속 둬야 한다.
