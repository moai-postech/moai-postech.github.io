# 2026-11-26 강의 출처 글자 대비 반영
작성자: Sangwoo Mo(sangwoomo) | 대상: `teaching/26f-data-engineering/slides/` | 도구: Codex

> **한줄 결론: 기존 공개19개 HTML의 본문·자산을 유지하고 공통 출처 글자색만 갱신.**

POSTECH 요구사항: 영향 없음. 크기·위치·표지·로고 변경 없음.

## 요청과 결정

사용자는 작은 회색 출처 글자 문제를 TODO에만 두지 말고 공통 스타일과 관련 자료에 적용하도록 명시했다. 기존 보조색 ink-3(#64748b)를 출처에 적용했다. 흰 배경 대비는 2.56:1에서4.76:1로 개선됐다. 크기·위치·글꼴·줄 수·본문·다른 역할의 ink-4는 유지했다.

## 기각한 안과 이유

- ink-4 토큰 자체 교체: 출처 외 도형·구분선·숫자까지 바뀜.
- 글자 확대·위치 이동: 요청한 대비 수정에 필요 없음.
- 기존 자료를 최신 source 본문으로 전면 재생성: 2·13·14강의 미배포 원문 변경까지 섞일 수 있어 기각. 생성기에 css-only 갱신 경로를 추가해 기존 배포본의 내용·자산을 보존.
- 출처 줄이 없는 장에 새 출처 삽입: 과목의 명시적 예외와 충돌.

## 검수

20개 작업본(템플릿+19개 덱)과19개 배포 HTML의 테마 밖 원문이 이전과 완전히 같음을 대조했다. 과목 환경(.venvs/imen891k)에서19개 deck-check 모두 통과. 19개 HTML의1118개 장과 출처색 계산, 기존 ink-4 토큰 보존을 브라우저에서 검사했다. 템플릿의 실제 출처는 수정 전후 x·y·폭·높이·13px·글꼴이 같았다. 현행19개 강의는 원래 화면 출처 줄이0개라 출력 화면에 변화가 없으며 PDF는 다시 만들지 않았다. 템플릿의 두 출처 예시는 실제 색 변경을 눈으로 확인했다. AX 과목의 출처는 이미 ink-3이고 세미나의 보조색도 기준 이상이라 바꾸지 않았다. 외부 AllInOne 서식·아카이브·원본 자료는 수정하지 않았다.

읽은 규칙: 상위9_code·academic-profile 및 사이트 AGENTS. 대상 파일의 기존 이력과 수정 전 로컬/사이트 동일성을 확인했다. 사이트 테마·페이지 구성·개인 사이트·CV의 사실은 바꾸지 않았다.

최종 검수: 독립 검토에서 과목·사이트39개 HTML의 비테마 내용 보존,19개 사본 일치, 템플릿 색만 변경과 PDF 유지 판단을 확인하고 제출 가능 판정. 증거는 과목 reviews/source-label-contrast/에 보존.
